========= ABOUT
Программа позволяет решать системы линейных уравнений с помощью метода Холецкого. 

Метод работает для положительно определённы, Симметричных матриц и основывается на разложении симметричной матрицы на произведение нижне-диагональной и транспонированной.

========= Файлы
main.cpp:
    Cодержит проверки, инициализации матрицы, векторов и освобождения памяти.
input.cpp
     Jтвечает за чтение файла с матрицей, а также за print матрицы.
funk.cpp
     Cодержит функцию реализации вектора b, функцию максимума, функцию f(4) и функцию генерации матрицы от функции f.
Solution.cpp
    Cодержит метод реализации метода Холецкого.

========= Архитектура
Проект собирается файлом Makefile.
main.cpp подключает все .cpp-файлы через header-файлы .h

========= КАК ЗАПУСКАТЬ?
make
make run_(номер по выбору)
make test - запустит тесты.

========= Положительная определенность
Запустив 
make run_1

Затем 
make run_6

Можно наглядно увидеть, как изменение двух элементов симметричной матрицы ломает метод: 
заменяем тройку на четверку, и матрица перестает быть положительно определённой.
